# Lecture format prototypes (unlisted)

Two alternative formats for the Session 4 CRS lecture, published so they can
be tried on a phone. They aren't linked from the site's navbar or lecture
list, and they're excluded from site search (`search: false`).

| Folder | Format | For |
|---|---|---|
| `crs-reading/` | the regular CRS page + landscape full-screen script (`shared/fullscreen-landscape.html`) | testing full screen on Android |
| `crs-deck/` | short reveal.js deck (~14 slides): core concepts and Predict moments only | presenting in class (the lecture page is the reading) |
| `crs-slides/` | the whole lecture as reveal.js slides (58) | superseded by `crs-deck/` |
| `crs-scrolly/` | scrollytelling page (closeread extension, in `../_extensions/`) | reading at home / on phones |
| `shared/` | the datum figure (`datum_figure.js`) and lecture styles both use | |

The `index.qmd` files are generated from templates kept with the course
planning materials, so edit those and rebuild rather than editing here.
